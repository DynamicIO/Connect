# Connect Four Arena

A visually rich Connect Four game with three modes:
- Vs CPU (single device)
- 2 Players on same device
- Online multiplayer via shareable room link

## Run locally

```bash
npm install
npm start
```

Open `http://localhost:3000`.

## Online mode

1. Choose **Online Link Match**
2. Click **Create New Room**
3. Click **Copy Invite Link** and send it to another player
4. Both players open the same link and play in real time
